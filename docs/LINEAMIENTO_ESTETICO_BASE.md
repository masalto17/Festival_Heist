# Festival Heist - Lineamiento estetico base

Fecha: 2026-09-16  
Estado: direccion visual seleccionada para producto real. No reemplaza validacion de UI ni pruebas con usuarios.

## 1. Decision tomada

La direccion principal del producto sera:

**Backstage punk pulido**, tomando como referencia principal:

- `entregables/assets/estetica/festival-heist-direccion-principal-D.png`

Y como referencia secundaria para componentes de desafio:

- `entregables/assets/estetica/festival-heist-componentes-desafio-B.png`

La opcion D define el mundo visual general. La opcion B aporta mecanicas visuales para adivinar, puntuar, robar el festival y jugar revancha.

## 2. Idea rectora

Festival Heist debe sentirse como si el usuario estuviera armando un festival propio desde el backstage: cajas de gira, cinta, papeles pegados, marcadores, luces de escenario, posters fisicos y energia de noche real.

La experiencia no debe sentirse como un formulario musical, ni como una app corporativa, ni como una plataforma de streaming. Tiene que sentirse como juego social cultural: armar, esconder, compartir, adivinar, robar y volver a jugar.

## 3. Personalidad visual

Palabras guia:

- nocturno;
- fisico;
- rebelde;
- compartible;
- cultural;
- competitivo;
- hecho a mano pero bien producido;
- joven sin ser infantil;
- local sin parecer amateur.

El equilibrio buscado es: **caos visual controlado**. Mucha textura y energia en fondos, posters y piezas de comunicacion; claridad y jerarquia fuerte en los controles de la app.

## 4. Paleta base

Colores principales:

- Negro escenario: `#08080A`
- Negro caja de gira: `#111114`
- Blanco papel sucio: `#F2EDE4`
- Magenta Festival Heist: `#FF1F8A`
- Lima acido: `#C8FF2E`

Colores secundarios:

- Cian electrico: `#25D7FF`
- Naranja desafio: `#FF6A2A`
- Gris cinta / metal: `#5B5B62`
- Papel envejecido: `#D8CDBB`

Uso recomendado:

- Magenta: marca, energia, accion principal.
- Lima: confirmacion, avance, llamados rapidos.
- Cian: opciones secundarias, contraste frio, datos o links.
- Naranja: desafio, alerta lúdica, revancha, tension de juego.
- Blanco papel: posters, tarjetas, etiquetas y zonas de lectura.

## 5. Materiales y textura

El sistema visual debe apoyarse en materiales reconocibles:

- papel roto;
- afiches pegados;
- cinta negra o rosa;
- marcador permanente;
- fotocopia;
- grano de impresion;
- polvo, rayas y desgaste;
- cajas de gira;
- pulseras de acceso;
- credenciales;
- puas, stickers y setlists.

Las texturas no deben tapar la lectura de botones, preguntas ni opciones. En UI funcional, la textura va principalmente en fondos, bordes, tarjetas y decoracion contenida.

## 6. Tipografia y tono grafico

Direccion tipografica:

- Titulares: condensados, pesados, de impacto, con tratamiento de poster o stencil.
- Acciones: mayusculas cortas, muy legibles.
- Texto de ayuda: sans simple, compacto, sin exceso de estilo.
- Acentos escritos a mano: solo para frases de energia, pistas o notas laterales.

Evitar:

- caligrafia excesiva;
- tipografias de terror;
- estetica metalera cerrada;
- letras ilegibles;
- look infantil tipo cartoon;
- apariencia de casino, hacking real o delito digital.

## 7. UI del producto

La UI debe ser mobile-first y rapida. La capa grafica puede ser intensa, pero la interaccion debe ser simple.

Pantallas clave:

1. **Inicio**
   - Gran marca Festival Heist.
   - CTA directo: `Arma tu festival`.
   - Fondo backstage o posterizado.
   - MasAlto, si aparece, como respaldo discreto.

2. **Crear festival**
   - Roles claros: `Abre`, `Rompe`, `Cierra`.
   - Cada rol puede verse como tarjeta/pase/backstage card.
   - Progreso visible y simple.

3. **Emergente**
   - Tres opciones con trato visual equivalente.
   - Ningun artista debe parecer privilegiado por defecto.
   - Mensaje cultural: descubrir, sumar, dar escenario.

4. **Poster listo**
   - Recompensa visual fuerte.
   - Debe parecer un afiche compartible, no una captura de formulario.
   - Slots visibles para juego/desafio.

5. **Desafio**
   - Tomar componentes de referencia B.
   - Usar pistas, puntaje, avance y revancha.
   - Debe entenderse en segundos: alguien oculto su festival y vos intentas descubrirlo.

## 8. Sistema del desafio

Componentes a tomar de la opcion B:

- tarjetas de pista;
- siluetas o slots tapados;
- marcador de puntaje tipo `3/4`;
- CTA `Roba el festival`;
- CTA `Revancha`;
- CTA `Crea el tuyo`;
- acentos naranja para tension de juego;
- papel, cinta y marcador para que la mecanica parezca fisica.

Regla visual: el desafio debe sentirse como una mision social entre amigos, no como examen ni trivia externa.

## 9. Poster compartible

El poster es la recompensa central del MVP.

Debe funcionar en:

- historia vertical;
- imagen cuadrada;
- captura dentro del link compartido;
- vista previa dentro del desafio.

Caracteristicas:

- fondo de crowd/backstage/fotocopia;
- titulo Festival Heist dominante;
- lineup o slots bien jerarquizados;
- detalles escritos a mano;
- textura de afiche real;
- espacio para ocultar artistas cuando sea desafio;
- CTA visual para `Adivina`, `Revancha` o `Crea el tuyo`.

## 10. Emergentes

El tratamiento de emergentes debe apoyar el objetivo principal del proyecto: impulsar artistas autorizados.

Principios:

- mismos tamaños de tarjeta para todos;
- sin insertar visualmente a Ekiss por encima de otros;
- no mezclar sponsor con curaduria artistica;
- lenguaje simple y positivo;
- evitar promesas de fama, reproducciones o demanda real.

Frases de tono posible:

- `Nuevos sonidos, grandes historias`
- `La proxima escena puede estar aca`
- `Sumalo al lineup`
- `Mas escenarios para mas artistas`

## 11. Sponsor y aliados

El sponsor debe poder existir sin romper la experiencia.

Direccion:

- placement identificado como patrocinado;
- pieza integrada al lenguaje de backstage;
- no convertir la pantalla en banner publicitario;
- no mezclar sponsor con eleccion artistica;
- no usar colores del sponsor como paleta dominante del producto.

## 12. Lo que no debe pasar

Evitar:

- app generica de musica;
- estetica corporativa premium como direccion principal;
- dashboard antes que juego;
- neones limpios sin textura;
- exceso de glassmorphism;
- imitacion de Spotify u otra plataforma;
- cyberpunk de hacking;
- casino, apuestas o delito real;
- mockups con artistas reales no autorizados;
- promesas comerciales no validadas.

## 13. Criterio de exito visual

La direccion funciona si una persona entiende rapidamente:

1. Estoy armando mi festival.
2. Hay artistas emergentes para descubrir.
3. El resultado es un poster compartible.
4. Mis amigos pueden intentar adivinarlo.
5. Puedo jugar revancha o crear el mio.

Y si visualmente se siente:

- intenso;
- memorable;
- joven;
- cultural;
- compartible;
- suficientemente claro para jugar desde el celular.
