# Festival Heist

Festival Heist es un MVP web social de descubrimiento musical impulsado por MasAlto. La experiencia permite que una persona arme un festival propio, lo comparta como desafio y genere senales medibles sobre gustos, artistas emergentes, comunicacion y oportunidades comerciales.

Este repositorio consolida la especificacion base, las fuentes aprobadas, los entregables de presentacion y el lineamiento actualizado para desarrollo.

## Estado actual

- Estado: preparacion de MVP y material comercial.
- Fecha de consolidacion: 2026-09-15.
- Producto: no lanzado.
- Traccion, viralidad, sponsors, ingresos e inversion: no demostrados.
- Presentaciones: aprobadas como material de conversacion y venta preliminar, no como evidencia de resultados obtenidos.

## Objetivo del MVP

Validar si Festival Heist puede producir una experiencia simple, compartible y medible que:

- impulse artistas emergentes autorizados;
- genere una dinamica social de creacion, desafio y revancha;
- entregue datos agregados utiles para MasAlto, productoras, sponsors y aliados;
- sea comercializable como piloto patrocinado sin comprometer promesas de viralidad o resultados.

La prioridad de negocio se conserva en este orden:

1. Impulsar a Ekiss y otros artistas emergentes autorizados.
2. Crear un juego entretenido que pueda crecer organicamente.
3. Conocer demanda e interes declarado para orientar shows, comunicacion y alianzas.

## Reglas importantes

- No usar Spotify Web API, OAuth ni datos de escucha como base del MVP.
- No presentar elecciones del juego como demanda real de shows.
- No prometer viralidad, ingresos, reproducciones ni contrataciones.
- Usar artistas emergentes solo con autorizacion y materiales oficiales.
- Mantener separadas curaduria artistica, sponsorship y pauta.
- Etiquetar claramente todo contenido patrocinado.
- Medir con denominadores: impresion, inicio, finalizacion, share, apertura, desafio, escucha, eleccion y click.
